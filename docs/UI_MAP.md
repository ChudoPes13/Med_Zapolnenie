# UI Map

## Верхняя панель

- `МедЖарвис`: название локального ассистента.
- Подзаголовок: текущий профиль приема, который определяется из диалога (`Амбулаторный прием`, `нижние конечности`, `стоматология`).
- `Черновик` / `Подтверждено врачом`: статус подписи врачом.
- `N крит.`: число открытых критических замечаний.
- `WS ...`: состояние WebSocket аудиопотока.

## Левая колонка

- Кнопка микрофона: старт/стоп записи. Каждый конец речи по VAD отправляет фрагмент на распознавание и проверку.
- `НК пример`: только ручной тестовый пример про нижние конечности; он не отправляется автоматически.
- `Отправить`: ручная отправка текущего текстового фрагмента, эквивалент одного VAD-сегмента.
- `Завершить`: финализация записи, суммаризация всего диалога и полная проверка данных.
- `Диалог`: список распознанных или вручную отправленных фрагментов.

## Центральная колонка

- `ЭМК`: структурированное состояние карты.
- `Жалобы`, `Анамнез`, `Объективно`: общие секции приема.
- `Нижние конечности`: появляется только при соответствующем профиле; содержит сторону, область, отек, кожу, пульс, чувствительность и движения.
- `Стоматология`: появляется только при явном стоматологическом контексте; содержит FDI, одонтограмму, перкуссию, термопробу и ЭОД.
- `Диагноз и рекомендации`: МКБ-кандидат, рекомендации и финальный итог после завершения записи.

## Правая колонка

- `Контроль`: realtime quality checker. После каждого VAD-сегмента показывает недостающие поля по текущему профилю.
- `КР Минздрава`: контур доказательности. Сейчас это видимая заглушка `is_stub=true`, пока не подключена реальная BM25-база.
- `Подтвердить`: врач подтверждает карту перед экспортом.
- `JSON`, `HTML`, `1C`, `DOCX`: экспорт включается только после подтверждения врача.
